05 FIELD NOTES

        
Things I believe.

      

      

        
NOTE / 001
If something takes more than two steps, automate it.

        
NOTE / 002
If it takes one step, automate it anyway.

        
NOTE / 003
Good software should disappear into the system around it.

        
NOTE / 004
If it needs to be complicated underneath, that's fine. Just don't make the person using it deal with that complexity.
